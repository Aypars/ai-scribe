# AI-SCRIBE frontend

Next.js arayüzü. Kurulum, mimari ve API için depo kökündeki [README.md](../README.md) dosyasına bak.

```bash
npm install
npm run dev
```

Uygulama: http://localhost:3000

API adresi varsayılan `http://localhost:8000`. Değiştirmek için `.env.local`:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```
